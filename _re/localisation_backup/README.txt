Бекап локализации (игра этот каталог не читает).

Vic2 грузит только *.csv из папки localisation/.
Файлы *.csv.bak, скрипты и этот каталог _re/ игрок не видит.

a.csv.bak
    Полный снимок старого localisation/a.csv до нарезки.

c.csv.bak
    Английский дамп ванили (бывший Victoria 2/localisation/c.csv).
    Убран из загрузки: дублировал русские ключи мода (~22616 предупреждений).
    Копия также лежит в Victoria 2/localisation_backup/c.csv.bak.

vanilla_identical.csv.bak
    190 ключей, текст которых совпадал с ванильным c.csv.
    После отключения c.csv они снова в моде: localisation/vanilla_keep.csv
    (плюс 83 ключа, которые были только в ванили).

Старые a.csv.bak* из localisation/ перенесены сюда же.

Чтобы вернуть один файл: скопировать a.csv.bak обратно в
localisation/a.csv и убрать фрагменты. Не держать a.csv рядом
с фрагментами — тогда каждый ключ задублируется.
